# Contributing

This list is generated every night from [VibeCruiser](https://vibecruiser.com/?ref=picks)'s database, so pull requests
and edits to the README are overwritten by the next run. To be listed, submit your project at
[vibecruiser.com/submit](https://vibecruiser.com/submit?ref=picks): once it is live on VibeCruiser and has a public
GitHub repo, it appears here under its topics. To claim a listed project as its creator, link
back to its VibeCruiser page as described on [the creators page](https://vibecruiser.com/creators?ref=picks). To have a
project removed, open an issue in this repository (or take the demo down: a project that is no
longer live drops off VibeCruiser and out of this list on the next run). The list is released under CC0 (see [LICENSE](LICENSE));
each project listed keeps its own licence.
