# VibeCruiser picks

Playable vibe-coded games, toys and generative art, picked from the 3101 live projects
on [VibeCruiser](https://vibecruiser.com). Every one runs in your browser from its creator's own site, with
nothing to install. Each entry links to its page on VibeCruiser and to its source on GitHub.

The list is regenerated from the VibeCruiser database every night, so it only lists projects
that are live right now. Last updated 2026-10-15. Or skip the list and
[start cruising](https://vibecruiser.com/cruise): one project fills the screen, press next for another.
