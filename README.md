# VibeCruiser Picks [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

Playable vibe-coded games, toys and generative art, picked from the 4243 live projects
on [VibeCruiser](https://vibecruiser.com/?ref=picks). Every one runs in your browser from its creator's own site, with
nothing to install. Each entry links to its page on VibeCruiser and to its source on GitHub.

The list is regenerated from the VibeCruiser database every night, so it only lists projects
that are live right now. Last updated 2026-10-16. Or skip the list and
[start cruising](https://vibecruiser.com/cruise?ref=picks): one project fills the screen, press next for another.

## Get your project listed

Made a game, toy or piece of generative art that runs in the browser?
[Submit it on VibeCruiser](https://vibecruiser.com/submit?ref=picks): a live demo URL is enough, a GitHub repo is optional.
Live projects with a GitHub repo show up here on the next nightly run. Then put the badge in your
README; it shows your project's live play count and links to its page (replace `YOUR-SLUG` with
the slug in your project's VibeCruiser URL, `vibecruiser.com/v/<slug>`):

```md
[![On VibeCruiser](https://vibecruiser.com/badge/YOUR-SLUG.svg)](https://vibecruiser.com/v/YOUR-SLUG?ref=badge)
```

[How listing, the badge and claiming work](https://vibecruiser.com/creators?ref=picks).
